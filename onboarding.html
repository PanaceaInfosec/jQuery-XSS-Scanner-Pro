About This Extension

The jQuery XSS Vulnerability Scanner is a security tool designed to help developers and security professionals identify potential Cross-Site Scripting (XSS) vulnerabilities in websites that use jQuery.

In April 2020, the jQuery team released version 3.5.0 which fixed several critical security vulnerabilities (CVE-2020-11022, CVE-2020-11023) that had existed in previous versions. Websites using older versions of jQuery may be vulnerable to XSS attacks through these known vulnerabilities.

This tool is for educational and testing purposes only. Always obtain proper authorization before testing for security vulnerabilities on any website you don't own.

Understanding XSS Vulnerabilities

What is XSS?

Cross-Site Scripting (XSS) is a type of security vulnerability that allows attackers to inject malicious client-side scripts into web pages viewed by other users. These attacks occur when an application takes untrusted data and sends it to a web browser without proper validation or encoding.

jQuery XSS Vulnerabilities

jQuery versions prior to 3.5.0 contain vulnerabilities in the way they parse and manipulate HTML. These vulnerabilities can allow attackers to execute malicious JavaScript even when seemingly safe HTML is processed.

Common jQuery XSS Attack Vectors

  • Unsafe use of the $.html() method with untrusted content
  • Vulnerabilities in jQuery's HTML parsing (CVE-2020-11022/11023)
  • Improper handling of nested elements that can lead to script execution
  • Unsafe use of jQuery's selector/constructor with untrusted input
